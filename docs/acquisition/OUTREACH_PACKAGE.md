## Positioning

Auction is a visual-commerce product comprising a web experience and browser extension. The intended customer journey is:

**Product image or shopping page → product identification → retailer discovery → offer matching/filtering → price comparison → retailer destination.**

The acquisition discussion can cover the Auction software assets and transferable IP, subject to due diligence and a definitive agreement.

## Outreach rules

- Lead with the buyer-specific strategic fit rather than a generic "app for sale" message.
- State the asking price consistently as **$1,250,000 negotiable**.
- Do not claim traction, revenue, retailer coverage, accuracy rates, patents, proprietary datasets, or completed integrations unless they can be demonstrated.
- Do not send source code, credentials, database access, API secrets, or private repository access in first contact.
- First-contact package: short pitch + visual overview + demo. Technical due diligence follows genuine interest.

## Due-diligence package to prepare before serious negotiations

1. Live website demonstration.
2. Browser-extension demonstration.
3. Current architecture diagram.
4. Inventory of repositories, code, domains, branding, and other transferable assets.
5. Third-party dependency/API inventory and transfer restrictions.
6. Test/CI evidence and known limitations.
7. Usage/revenue metrics, if any, supported by records.
8. IP ownership/provenance review.
9. Security/credential cleanup before repository access.
10. Transaction asset schedule defining exactly what the buyer receives.
